# AeroGlow-Supply-Chain-Optimization
An end-to-end supply chain analytics project built using Excel and Power BI. Analyzed Q1–Q2 2026 shipment performance, identified vendor stockout risks ($81.1K spend audit, 614 short units), modeled Reorder Points (ROP) &amp; Safety Stock, and designed an interactive Executive Control Tower dashboard to elevate OTIF performance above 85%.
